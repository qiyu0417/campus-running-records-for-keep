Fit Tool

Fit Tool 是一个用于生成 keep 校园跑跑步数据（时间、距离、速度、配速、心率、卡路里消耗等）的软件。
本工具遵循 CC BY-NC-SA 4.0 协议开源。
开发者为 Ruomu Yunxi。
B站账号 [**@黑心商家瑶瑶**](https://space.bilibili.com/439315192)

## 使用说明（网盘版，下载即用）

1. 下载 `fit-tool.exe`（或解压完整文件夹），双击运行。
2. 程序会自动启动本地服务并用浏览器打开工具页面。
3. 选择地图源、设置参数、在地图上点击绘制轨迹点。
4. 点击「预览」在右侧地图回放轨迹并查看实时配速/心率，点击「生成 FIT 文件」下载 `.fit` 文件。
5. 将文件导入 keep 校园跑 App。
6. 使用完毕后关闭命令行窗口即可。

## 路线模式

在「路线模式」下拉框中可选：

- **环形（默认）**：首尾自动相连闭合，支持「圈数」重复多圈，适合校园操场绕圈跑。
- **线性（单程）**：不闭合，只沿绘制的路线走一遍，此时不显示「圈数」设置。

切换模式会实时刷新地图上的闭合线，并重新计算总距离。

## 地图源

工具支持多种地图源，可在页面左上角切换：

| 地图源 | 是否需要 Key | 坐标系 | 说明 |
| ------ | ------------ | ------ | ---- |
| OpenStreetMap | 否 | WGS-84 | 国际图源，无需 Key |
| Google 地图（标准/卫星） | 可选 | WGS-84 | 中国大陆区域数据有偏移，可勾选下方「坐标纠偏」 |
| 腾讯地图 | 可选 | GCJ-02 | 火星坐标，默认已勾选纠偏 |

- 默认使用 Google 标准地图。可填写 Key 的图源会在「地图源」下方显示输入框，输入后自动生效并保存在本地浏览器。
- 「坐标纠偏（GCJ-02 → WGS-84）」：当图源是火星坐标（腾讯等）时勾选，生成轨迹会自动转回 WGS-84，保证导入 Keep 后位置正确。
- 切换地图源会清空已绘制的轨迹，避免不同坐标系混用。

## 打包成单个 exe（开发者）

需要自行安装 Node.js 20+；仓库不包含 Node.js 或 `node_modules`。

```bash
npm install          # 首次安装依赖
npm run build:sea    # 生成 dist/fit-tool.exe
```

打包脚本会：用 esbuild 把后端与前端静态资源打成一个文件 → 用 Node SEA 生成 blob → 注入 `node.exe` 生成单文件 `fit-tool.exe`。

> 注意：生成的 exe 未签名，Windows 首次运行可能弹出 SmartScreen 提示，点「更多信息 → 仍要运行」即可。

- 添加定位功能，可自动获取当前位置

V1.2：
- 扩充文件数据量，增加卡路里消耗数据及步频数据（不直接显示，但输出相关数据）

V1.3：
- 支持多个地图源（OpenStreetMap / Google / 腾讯地图），Key 可从前端自行填写
- 增加 GCJ-02 → WGS-84 坐标纠偏，保证火星坐标图源生成的轨迹位置正确
- 补充 FIT 的 LAP 消息、enhanced_speed / enhanced_avg_speed 字段，提升 Keep 识别兼容性
- 支持打包成单个 `fit-tool.exe`，双击即用，无需安装 Node
- 修复：全新环境依赖安装后服务无法启动、圈数无上限导致内存耗尽、距离显示与实际生成不一致等问题

V1.4：
- 新增「路线模式」开关：环形（自动闭合、支持圈数）/ 线性（单程不闭合），线性模式自动隐藏圈数设置
- 配速改为「短暂加速后稳定在目标配速附近，±10% 轻微波动」
- 移除配速/心率预览图表，改为地图轨迹回放 + 实时配速/心率
- 更真实的跑姿数据：步频（含 fractional_cadence 半拍精度）、步幅、触地时间、触地时间占比、垂直振幅、垂直步幅比、总步数（total_cycles）写入 FIT，令文件更接近真实 Garmin 记录
